# 디자인 (UI/UX)

## 와이어프레임
- 캔버스: https://claude.ai/artifact/KpLCm3tEZH3wpA2hPbwe9d
- 기준: PC 웹 1280px
- 각 화면의 Play 버튼을 누르면 클릭하면서 흐름을 볼 수 있어요

## 화면 목록
| 번호 | 화면 | 범위 |
|---|---|---|
| 01 | 학과·학번 선택 | Must |
| 02 | 이수 과목 입력 (검색, 선택 칩, 졸업인증 체크) | Must |
| 03 | 판정 결과 (총학점 / 전공필수 / 교양필수 / 졸업인증 카드) | Must |
| 04 | 다음 학기 추천 (지금 담을 것 / 미뤄도 되는 것) | Should |
| 05 | 교양 취향 설문 | Should |
| 06 | 교양 추천 결과 | Should |
| - | 예외 화면: 로딩, 네트워크 오류, 검색 결과 없음, 과목 0개, 모두 충족 | Must |
